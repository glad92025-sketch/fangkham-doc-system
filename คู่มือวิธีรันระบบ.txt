โฟลเดอร์โปรเจกต์อยู่ที่หน้า Desktop:
-> Desktop\fangkham-doc-system\

--------------------------------------------------------------------------------
1. สิ่งที่ต้องมีในเครื่องคอมพิวเตอร์ก่อนรัน
--------------------------------------------------------------------------------
ระบบนี้เขียนด้วย Laravel 11 (PHP) จึงจำเป็นต้องมีสภาพแวดล้อม PHP & Composer

*** วิธีที่ง่ายที่สุดสำหรับ Windows (แนะนำอย่างยิ่ง) ***
ดาวน์โหลดและติดตั้งโปรแกรม "Laragon" (ฟรี ใช้ง่ายที่สุดสำหรับคนทำเว็บ Laravel)
- ลิงก์ดาวน์โหลด: https://laragon.org/download/ (เลือกเวอร์ชัน Laragon - Full)
- หลังติดตั้งเสร็จ:
  1. เปิดโปรแกรม Laragon
  2. กดปุ่ม "Start All"
  3. คลิกขวาที่ Laragon -> Quick app -> หรือเปิด Terminal จาก Laragon

(หรือถ้ามี XAMPP อยู่แล้ว ให้ลง Composer เพิ่มเติมจาก: https://getcomposer.org/)

--------------------------------------------------------------------------------
2. วิธีเปิดรันเซิร์ฟเวอร์ (Local Server)
--------------------------------------------------------------------------------
วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียว
  - เข้าไปในโฟลเดอร์ "fangkham-doc-system"
  - ดับเบิ้ลคลิกไฟล์ "START_SERVER.bat"
  - ระบบจะตรวจสอบความพร้อมและเปิดหน้าเว็บให้อัตโนมัติ

วิธีที่ 2: สั่งผ่าน Command Prompt / PowerShell
  1. เปิด PowerShell หรือ CMD เข้าไปที่โฟลเดอร์โปรเจกต์:
     cd C:\Users\Obiwan\Desktop\fangkham-doc-system

  2. สั่งติดตั้ง Library (ทำเฉพาะครั้งแรก):
     composer install

  3. คัดลอกไฟล์ตั้งค่าและสร้างคีย์:
     copy .env.example .env
     php artisan key:generate

  4. สั่งสร้างตารางและนำเข้าข้อมูลพนักงาน 48 คน:
     php artisan migrate --seed --class=UserStaffSeeder

  5. สั่งเปิดเซิร์ฟเวอร์:
     php artisan serve

  6. เปิดเบราว์เซอร์ (Chrome / Edge) แล้วพิมพ์:
     http://localhost:8000

4. การเชื่อมต่อ Google Drive 5 TB
--------------------------------------------------------------------------------
1. ไปที่ Google Cloud Console (https://console.cloud.google.com/)
2. สร้าง Service Account และดาวน์โหลดไฟล์ JSON Key
3. นำไฟล์ JSON มาวางไว้ที่:
   Desktop\fangkham-doc-system\storage\app\google-service-account.json
4. คัดลอกอีเมลของ Service Account (เช่น xxx@xxx.iam.gserviceaccount.com)
5. ไปที่ Google Drive (5 TB) กดแชร์โฟลเดอร์หลักให้ Service Account เป็น "ผู้จัดการเนื้อหา (Content Manager)"
*หมายเหตุ: ในช่วงทดสอบ หากยังไม่ได้ใส่ไฟล์ Key ระบบจะจำลองการทำงาน (Mock Mode) ให้อัตโนมัติโดยไม่ Error*
